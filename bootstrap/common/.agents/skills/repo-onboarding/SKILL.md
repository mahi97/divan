# Repo Onboarding

Help a new contributor understand this project's structure, conventions, and key files.

## When to Use

- A new contributor asks "how does this project work?"
- You need to orient yourself in an unfamiliar codebase

## Steps

1. Read `README.md`, `docs/architecture.md`, `docs/commands.md`
2. List top-level directories and their purposes
3. Identify entry point, config files, and CI config
4. Check if tests pass and linter is configured
5. Produce an onboarding summary

## Output

Produce a summary with: purpose, structure, key files, getting started commands,
and a health check (tests, lint, docs status).

## Safety

Read-only. Do not modify files.
