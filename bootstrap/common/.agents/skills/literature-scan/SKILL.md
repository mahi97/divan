# Literature Scan

Find and summarize relevant papers or references.

## When to Use

- Starting work in a new area
- Looking for prior art on a technique
- Operator asks for reading recommendations

## Steps

1. Clarify topic and scope
2. Search for references (web, arxiv, semantic scholar)
3. Create `docs/literature/NNNN-title.md` for each reference
4. Write a summary connecting the references
5. Suggest a reading order

## Output

List of references with key findings, summary, and recommended reading order.

## Safety

- Distinguish verified papers from metadata-only recommendations
- Always include proper citations with links
- Do not fabricate titles, authors, or findings
