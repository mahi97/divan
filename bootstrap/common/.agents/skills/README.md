# Agent Skills

This directory contains starter skills for AI coding agents (Codex, etc.).

## Available Skills

| Skill              | Purpose                                       |
|--------------------|-----------------------------------------------|
| repo-onboarding    | Help new contributors understand this project  |
| legacy-rewrite     | Safely modernize legacy code                   |
| experiment-runner  | Run and document experiments                   |
| literature-scan    | Find and summarize relevant papers             |

Each skill has a `SKILL.md` with usage instructions, steps, and output format.
