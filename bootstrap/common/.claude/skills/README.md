# Claude Code Skills

This directory contains starter skills for Claude Code.

## Available Skills

| Skill              | Purpose                                       |
|--------------------|-----------------------------------------------|
| repo-onboarding    | Help new contributors understand this project  |
| legacy-rewrite     | Safely modernize legacy code                   |
| experiment-runner  | Run and document experiments                   |
| literature-scan    | Find and summarize relevant papers             |

## Adding New Skills

Create a new directory with a `SKILL.md` file:

```
.claude/skills/
  my-new-skill/
    SKILL.md
```

See existing skills for the expected format.
